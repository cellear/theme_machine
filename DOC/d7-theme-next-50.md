# D7 Theme Next 50 Queue

Ranked shortlist from `DOC/d7-theme-catalog.tsv` for practical emulator testing.

## Method

- Source catalog: `DOC/d7-theme-catalog.tsv` (761 projects).
- Excluded themes already imported/tested in `INCOMING/` (18 names including nested subthemes).
- Hard-excluded obvious non-targets based on title/teaser keywords:
  - base/starter/framework/sub-theme
  - admin/dashboard themes
  - explicit framework-tech stack themes (`bootstrap`, `tailwind`, `foundation`, `material`, `uikit`, `omega`, `zen`, `radix`, etc.)
  - projects advertising Drupal 8/9/10/11 in listing text
  - install-only themes
- Scored remaining candidates with bonuses for:
  - simplicity keywords (`simple`, `clean`, `minimal`, `basic`, `classic`, `lightweight`)
  - generic layout/compatibility signals (`responsive`, `html5`, `css3`, `tableless`, `fluid`, `fixed width`)
  - slightly older listing pages (small age bonus)
- Candidate pool after filtering: 446 themes.
