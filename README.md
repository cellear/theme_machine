# Theme Machine

## What it is

The heart of this repo is a Backdrop module — currently called **`d7_theme_compat`**, though that name is provisional — that makes Drupal 7 themes run natively on Backdrop, bridging the gap between D7's theme layer and Backdrop's. The module is actively being developed.

The rest of the repository — a Backdrop CMS install, ddev environment, and a set of utility modules — is the development scaffolding built to test it. Expect that to shrink or separate as the module matures.
